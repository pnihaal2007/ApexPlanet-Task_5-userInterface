# Data Analyst Internship Portfolio

## About
This repository is my master portfolio for the Data Analyst Internship. It brings together my internship tasks, sales-data analysis, technical skills, presentation material, and final reflection in one place.

## Capstone Project — Sales Data Analysis
The capstone uses a sales dataset containing order, customer, demographic, location, product, category, quantity, unit-price, and total-sales information.

### Objectives
- Clean and validate the sales dataset
- Explore sales performance
- Identify top products, categories, and cities
- Analyze customer and demographic patterns
- Create useful visualizations
- Summarize business insights

## Run the Analysis
1. Open this folder in VS Code.
2. Open the VS Code terminal.
3. Run:
   `pip install -r requirements.txt`
4. Then run:
   `python analysis.py`

The program creates an `output/` folder containing:
- `summary_statistics.csv`
- `category_sales.csv`
- `city_sales.csv`
- `product_sales.csv`
- `monthly_sales.csv`
- `sales_by_category.png`
- `sales_by_city.png`
- `monthly_sales_trend.png`
